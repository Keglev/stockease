    Type Declaration

    • cost: number

      Description

      Cost of goods sold: the sold units at the purchase price captured on each sale, less customer returns at that same captured price. Purchases and supplier returns are excluded - they move cash, not profit.

      Example

      40
    • deleted: boolean

      Description

      Soft-deleted products still appear; history stays reportable

      Example

      false
    • grossProfit: number

      Description

      Revenue less cost of goods sold; unsold stock does not reduce it

      Example

      60
    • name: string

      Example

      Widget
    • productId: number

      Format: int64

      Example

      3
    • revenue: number

      Description

      Sold units at their sale price, less customer returns at the same price

      Example

      100
    • sku: string

      Example
