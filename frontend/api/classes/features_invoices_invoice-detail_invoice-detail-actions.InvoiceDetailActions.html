    Class InvoiceDetailActions

    The admin lifecycle of one invoice: closing it, marking it paid, and deleting it, each behind a confirmation prompt.

    Remarks

    Provided by the invoice detail component rather than in root, matching the returns collaborator beside it: these actions only run from an open detail page and the state they read belongs to that page's lifetime.

    The coupling is one connect call. The page keeps the invoice signal, the shared in-flight flag and the route-derived id, because they are the page's; this collaborator owns the five services its own bodies use, including the admin check that only these three guards read.
