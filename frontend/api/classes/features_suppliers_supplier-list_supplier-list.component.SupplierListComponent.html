    Class SupplierListComponent

    The supplier register: the whole list, with create, edit and delete.

    Remarks

    The register is fetched unpaged because the dialogs and the delete guard read the same array the table pages over. The paging itself is not this page's concern.

    • exportCsv(): void

      Downloads the loaded register, the way each reports tab downloads its table.

      Every row the page holds, not the visible page: the list pages every client-side, over an array that is already in memory in full - so there is no unpaged fetch to avoid here, and exporting one screenful of a register the user already has would be the surprising answer.
