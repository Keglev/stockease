    Class AuditService

    Reads the product change log from the two audit endpoints, which differ only in what they select by. Both are open to either role: the audit trail is transparency rather than administration, and the backend's own hasAnyRole says so.

      Reads recent changes across every product, enriched with the username and the product's identity.

      A different row type from the two lookups above, because it answers a different question: those select by an ID the caller already holds, while this one has to say whose change and to what. Omitted bounds are left off the request entirely, as on every other period endpoint.
