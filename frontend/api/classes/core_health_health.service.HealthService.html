    Class HealthService

    Probes the backend's database-backed liveness endpoint and times the round trip. The endpoint sits at the server root rather than under /api and is the only one the backend permits without authentication, so the probe works whether or not a token is present.

    • check(): Observable<HealthProbe>

      Performs one probe and reports liveness with the latency measured around the request.

      latencyMs is API round-trip time as seen from the browser - network, TLS and server handling together. It is deliberately NOT presented as database lag: the honesty of the label is the point, and the endpoint reports only whether the DB probe passed, not how long it took. A failed call reports down with the measured latency rather than throwing, so the caller's polling stream survives an outage.

      Returns Observable<HealthProbe>
