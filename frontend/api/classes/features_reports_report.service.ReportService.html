    Class ReportService

    Reads the backend's reporting endpoints, whose list responses all return their records bare. It lives under features/reports because the reports pages are its primary home; the dashboard consuming it is deliberate cross-feature reuse, the same precedent as the shared positive-price validator.

    stockHistory

    • stockHistory(
          productId: number,
          from?: string,
          to?: string,
      ): Observable<
          { cumulativeSoldUnits: number; date: string; stockLevel: number }[],
      >

      Reads one product's stock level and cumulative sales per day it moved. Bare array.

      The window narrows which points come back, not where the running totals start, so a short period over a long-lived product still opens at the level it had reached.

      Parameters

      • productId: number

        product to chart

      • Optionalfrom: string

        first day to return, as an ISO date

      • Optionalto: string

        last day to return, as an ISO date

      Returns Observable<{ cumulativeSoldUnits: number; date: string; stockLevel: number }[]>
