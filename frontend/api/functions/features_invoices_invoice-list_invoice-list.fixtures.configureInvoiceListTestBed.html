      Builds the ledger over the given rows, and answers with it and the stubs it was wired with.

      One function rather than a copy per spec file, so the runner sees one context configuration across both of them: a difference here would fork the compilation the specs share.

      `download` is passed in rather than built here, because it is a test double from the runner and this file is compiled without the runner's types.
