      Builds the create payload from a form draft, omitting every key the invoice does not carry. Absent keys are left out entirely rather than sent as null.

      Parameters

      • draft: InvoiceDraft

      Returns {
          customerId?: number | null;

          interestRate?: number | null;
          invoiceNumber: string;
          items: { productId: number; quantity: number; unitPrice: number }[];
          supplierId?: number | null;
          type: "PURCHASE" | "SALE";
      }

      • OptionalcustomerId?: number | null

        Format: int64

        Description

        Optional on SALE invoices (absent means an anonymous cash sale); must be absent on PURCHASE

      • dueDate: string

        Format: date

        Description

        Required; message: "Due date is required."

        Example

        2026-03-01
      • OptionalfineValue?: number | null

        Description

        Optional, must not be negative; defaults to zero

      • OptionalinterestRate?: number | null

        Description

        Optional, must not be negative; defaults to zero

      • invoiceNumber: string

        Description

        Operator-assigned business identifier: the supplier's document number on a purchase, the operator's own number on a sale. Must be unique among invoices that are not soft-deleted - a deleted invoice's number may be reused. Rejected with 409 when it collides.

        Example

        RE-2026-0117
      • items: { productId: number; quantity: number; unitPrice: number }[]

        Description

        At least one line; message: "An invoice requires at least one item."

      • OptionalsupplierId?: number | null

        Format: int64

        Description

        Required for PURCHASE invoices; must be absent on SALE invoices

        Example

        7
