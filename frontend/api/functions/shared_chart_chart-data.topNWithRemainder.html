    Function topNWithRemainder

    • topNWithRemainder(
          slices: ChartSlice[],
          otherLabel: string,
          n?: number,
      ): ChartSlice[]

      Ranks slices by magnitude and collapses everything past the cut into a single labelled bucket. Ranking uses the absolute value because profit can be negative and a large loss is as chart-worthy as a large gain; the bucket's own value is the plain sum of the remainder, so it can come out negative, which is the honest figure rather than a defect.

      Parameters

      • slices: ChartSlice[]
      • otherLabel: string
      • n: number = CHART_TOP_N
